# Tactix — Tic-Tac-Toe AI

Tactix is a professional Human vs AI Tic-Tac-Toe application created for CodSoft Artificial Intelligence Internship Task 2.

## AI modes

- **Easy:** chooses a random legal move.
- **Medium:** mixes optimal and random moves.
- **Hard:** searches the complete game tree with Minimax.
- **Impossible:** uses Minimax with Alpha-Beta Pruning and cannot be defeated with legal play.

## Features

The application includes winner and draw detection, highlighted winning lines, new game and play again controls, first-player selection, AI-first play, persistent statistics, score reset, move history, hints, undo before the AI responds, keyboard shortcuts, synthesized sound effects, confetti, AI thinking and win animations, responsive layouts, and persistent light/dark settings.

## Run locally

1. Install Node.js 22 or newer.
2. Run `npm install` in this folder.
3. Run `npm run dev`.
4. Open the local URL displayed in the terminal.

No API key or server database is required. Settings and career statistics are stored locally in the browser.
